# 📖 股权穿透图谱 — 使用指南

> 如何利用 Obsidian 图谱视图探索股权穿透关系网络

## 🗺️ 图谱视图基础操作

### 打开图谱视图
1. 点击 Obsidian 左侧边栏的 **📊 图谱视图** 图标
2. 或按 `Ctrl+G` 快捷键

### 基本操作

| 操作 | 方法 |
|------|------|
| 🔍 缩放 | 鼠标滚轮 |
| ✋ 平移 | 拖拽空白区域 |
| 🎯 聚焦节点 | 点击节点 → 高亮其关联 |
| 📌 查看笔记 | 点击节点 → 右侧打开笔记 |
| 🔗 查看关系 | 悬停在节点上 → 显示连接数 |
| 🏷️ 筛选类型 | 顶部「筛选」→ 按标签过滤 |

### 节点含义

| 颜色 | 实体类型 | 说明 |
|------|----------|------|
| 🟠 橙色 | 自然人 | 最终实际控制人（穿透终点） |
| 🔵 蓝色 | 民营企业 | 非国有公司、壳公司、投资平台 |
| 🔴 红色 | 国有企业 | 国有资本控制的企业 |
| 🟢 绿色 | 境外实体 | 外资、QFII、境外法人 |
| ⚪ 灰色 | 基金/资管 | 通道型实体（继续向上穿透） |
| 🟣 紫色 | 合伙企业 | 有限合伙、员工持股平台 |
| 🟡 黄色 | 政府机构 | 国资委、财政厅等政府单位 |

> **越大越亮的节点 = 关联越多 = 越核心**

## 🔍 股权穿透分析流程

### 1. 从上市公司出发
打开图谱视图 → 搜索框输入股票代码（如 `603439`）→ 看到该公司的橙色/蓝色股东节点

### 2. 逐层追溯
点击蓝色企业节点 → 查看它的股东 → 继续点击 → 直到找到橙色节点（自然人）= **挖到了最终控制人**

### 3. 使用局部图谱
打开任意实体笔记 → 点击右上角 `···` → **打开局部图谱** → 只看以该实体为中心的关系网（默认2层深度）

### 4. 反向链接追溯
在笔记中打开右侧 **反向链接面板** → 看到"谁持有我"的完整列表

## 💡 高级技巧

### 标签筛选
在图谱视图的筛选器中：
- 只看 `#自然人` → 发现关键控制人
- 只看 `#壳公司` → 识别持股通道
- 组合 `#民营企业` + `#国有企业` → 观察民企与国资的股权交叉

### 深度穿透搜索
1. 图谱视图搜索 `shell_score` → 找到所有壳评分较高的实体
2. 搜索 `max_penetration_depth` → 找到穿透最深的案例

### 使用 Dataview 动态查询
在任意笔记中，Dataview 代码块会自动显示关联实体：
```dataview
TABLE type, stock_code, shell_score
FROM [[603326.SH]]
WHERE file.name != this.file.name
SORT type ASC
```

### Canvas 画布
打开 `股权穿透画布.canvas` 文件 → 拖拽实体卡片 → 手动创建连线 → 构建自定义分析视图

## 📊 典型分析场景

### 场景 1: 查老板
**问题**: "603439 的老板是谁？"
**操作**: 图谱搜索 `603439` → 点击蓝色节点 → 找到橙色自然人节点

### 场景 2: 查版图
**问题**: "张三控制了多少上市公司？"
**操作**: 搜索 `张三` → 局部图谱 → 看他持股的蓝色节点 → 继续往下看哪些是上市公司

### 场景 3: 查壳链
**问题**: "这只股票的控制链有多复杂？"
**操作**: 打开股票笔记 → 看「多级穿透链路」表格 → Mermaid 图直观展示 → 壳公司有 ⚠️ 灰色标记

### 场景 4: 风险排查
**问题**: "哪些公司的股权结构不合理？"
**操作**: 筛选 `#壳公司` + 高 `shell_score` → 控制链≥3层的公司 → 可能存在隐性关联交易风险
