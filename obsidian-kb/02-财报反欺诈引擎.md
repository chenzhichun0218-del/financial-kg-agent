# Phase 2：财报反欺诈引擎

> 工期：5-7天 | 依赖：Phase 1 | **建议先做（最独立）**
> 对应：[[任务3-财报反欺诈引擎]]

## 为什么先做？

不依赖 Agent 框架和图谱，直接用 pandas 规则 + LLM 即可出成果，最快验证可行性。

## 步骤

### 2.1 设计财务排雷规则库

硬编码 10-15 条专业规则 → [[财务排雷规则]]

### 2.2 跨科目勾稽计算引擎

用 Pandas 对 [[三大财务报表]] 做跨表关联计算，生成异常指标向量。

### 2.3 综合风险评分

Z-score → 加权求和 → 0-100 风险分

| 🔴 红色 70-100 | 🟡 黄色 40-69 | 🟢 绿色 0-39 |
|----------------|--------------|-------------|

### 2.4 LLM 生成研判报告

异常指标 + 原始数据 → Prompt Chain → 结构化报告（预警点 + 数据对比 + 可能造假模式）

### 2.5 评测与调优

在[[测试问答集]]上验证 F1 >= 85%，盲评优秀率 >= 80%
