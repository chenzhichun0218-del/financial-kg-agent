# 任务1：超长金融对话记忆增强与自适应路由

> 对应 Phase 4 | [[04-长对话记忆Agent]]

## 目标

开发支持 **0.5M+ Tokens** 窗口的上下文管理策略，10轮以上对话中精准召回关键金融指标、股票标的及用户意图。

## 核心能力

1. **[[分级记忆机制]]** — 长短期记忆分级，关键实体持久化
2. **[[意图识别路由]]** — 判断何时调用哪个工具
3. **[[自纠错机制]]** — "意图识别 → 工具选择 → 执行 → 验证"闭环

## 指标

| 指标 | 目标 |
|------|------|
| 关键事实召回率 | >= 90% |
| API 调用命中率 | >= 92% |
| 自纠错成功率 | >= 80% |
