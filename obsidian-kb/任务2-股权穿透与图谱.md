# 任务2：复杂股权穿透、事件脉络推演与 Agentic 图谱工具化

> 对应 Phase 3 | [[03-股权穿透与知识图谱]]

## 目标

构建静态结构与动态时序相结合的知识图谱，实现多层隐性控股链路穿透和舆情事件脉络聚合。

## 核心能力

1. **非结构化图谱抽取** — LLM 实体关系抽取 + [[Neo4j图数据库]]
2. **多链路寻路算法** — BFS/DFS 多跳穿透，带权重链路输出
3. **[[事件聚类]]** — Embedding + 聚类 + [[事件时间线]]

## 指标

| 指标 | 目标 |
|------|------|
| 穿透端到端准确率（>3层） | >= 85% |
| 事件关键节点召回率 | >= 85% |
| 工具调用延迟 | <= 5秒 |
